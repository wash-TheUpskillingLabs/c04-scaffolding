Module catalog

Help given in one situation gets logged. Modules form around the situations that keep coming back. Every module is optional.

    Recurring, with no module yet

    Tags that two or more logged situations share, where none of those situations has a module. These are candidates. When repeated help becomes a module, and who decides, is still open.

    Tags in use

    Tags grow from use. A tag not in the starting set is marked new.
