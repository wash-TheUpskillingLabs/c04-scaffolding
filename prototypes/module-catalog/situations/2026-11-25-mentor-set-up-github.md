Drawn from a real interview (#42), told by the participant, with names taken out. Not made up. It happened in C03, before and after the hackathon.

## The problem

GitHub was new to me ("what is that?"). Before the hackathon, a mentor set it up for me in person: "I kind of just had [him] just do it for me." When my team formed, I didn't know how to set it up for the team.

## What worked

The team met with the same mentor to get GitHub running as a team. I went back to him more than once ("I was a little bit repetitive").
